프로그램 이란 ?
=> CPU 에게 일을 시키기 위한 코드를 작성하는 것

프로그램언어의 종류
1. 인터프리터 언어
=> 사용자가 만든 소스 코드를 1줄씩 기계어로 변경해서 실행하는 것
=> 파이썬, Visual Basic
=> 장점 : 배우기 쉽고, 다양한 환경에서 실행가능
=> 단점 : 느리고, 안전성이 좋지 않다

2. 컴파일 언어
=> 코드 전체를 먼저 확인하고 전체를 기계어코드로 변경
=> C/C++/C#/Java/Rust/Swift 등의 대부분의 프로그래밍 언어
=> 장점 : 빠르고, 인터프리터 보다 안전
=> 단점 : 인터프리터 보다 배우기 어렵다
------------------------------------------------------

3. 컴파일 언어의 종류
native 기계어를 생성하는 언어 : C/C++/Rust     - 빠르지만, 실행파일이 플랫폼 호환성 없다
중간언어(가상머신에 의해 실행)를 생성하는  언어 : C#, Java - 약간 느리지만 실행파일호환성높다

4. CTS, CLR, BCL 용어 정리해 두세요 - 4page

5. .Net 이란 ?
IL CODE 를 실행하기 위한 실행환경
=> CLR, BCL 등을 배포 해서 설치 할때 ".net" 을 설치 한다고 표현

=> 1.  .Net Framework : 최초 버전, PC 를 고려한 환경, 4.8 까지 개발됨
=> 2.  .Net Core         : 스마트 폰등의 환경을 고려한 버전 6.0 까지 개발됨
그래서 2010년 후반까지 위 2개 버전이 공존했음
2020년대 들어서 위 2개 버전이 아래의 용어로 통합니다.

=> 3. ".Net" - 버전 10.0 이 최신 버전. 보통 1년 단위로 update

6. 버전
=> C# 언어 자체의 버전 : 최신 14.0
=> .Net 버전 : 최신 10.0
     (C# 으로 작성된 코드를 컴파일 하고 실행하기 위해 필요한 도구(가상머신, CLR)들을 묶어서 배포하는 것)
-----------------------------------------------------------------------

7. C# 언어를 배우고 컴파일, 실행하려면 

방법 #1. Visual Studio 설치
	=> .Net 설치(C# 컴파일러, CLR, BCL 등 C# 프로그램을 실행하기 위한 모든 것 설치)
	=> 소스코드 편집기도 설치
	=> 디버거, 성능 측정등 다양한유틸리티 모두 설치
	=> IDE(통합 개발 환경) 이라는 용어 사용
	=> 초보자에게는 아주 좋고 편한도구..
	=> 실행시 약간 오버헤드 있습니다.(메모리등 요구 사항이 높음)

방법 #2.  .Net 별도 설치 + 원하는 편집기(VSCODE, 메모장, eclipse ....)
	=> 구글에서 ".Net" 검색후 1번째 링크에서 .Net 설치(visual studio 설치한 경우 필요 없음)
	=> 방법 #1 보다 가볍다. 완전 무료!
	=> 중/고급 사용자

8. Visual Studio 를 사용하지 않고 C# 을 컴파일 하는 방법
=> 1. 탐색기 실행후, 원하는 위치에 "WORK" 폴더 만드세요
=> 2. 명령 프롬프트 실행(윈도우 실행 버튼 누르고 "cmd" 실행)
=> 3. WORK 폴더로 이동 
	c:	  => C 드라이브로 이동
	cd \	  => C 의 루트 폴더로 이동
	cd A    => A 폴더로 이동        
	cd ..     => 상위 폴더 이동
=> 4. 명령 프롬프트에서 "dotnet new console" 하면 새로운 프로젝트가 생성됩니다.
=> 5. dotnet run  하면 현재 폴더에 있는 "program.cs" 가 빌드되어서 실행됩니다.
=> 6. 메모장(VSCODE) 등에서 "program.cs"를 열어서 소스 코드 편집하면 됩니다.

=> 7. dotnet run 하면 무조건 "Program.cs" 컴파일 되는데.. 다른 파일 컴파일 하려면 어떻게 하나요 ?
        => work.csproj 파일을 편집기에서 열어 보세요
	=> 이 파일에 어떤 소스를 컴파일 할지 표기해야 합니다.
